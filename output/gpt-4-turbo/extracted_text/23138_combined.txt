6) Train-test-split is a method available in scikit-learn that we used to split the data into training set and testing set. We use 30% of the total data for underrating and overfitting.
   - Overfitting is a phenomenon used where the machine learning model predicts too well on the training data that is seen data that doesn't work well on unseen data that is test data.
   - Where underfitting happens when the model performs steadily on the training data that is the seen data, that predicts steadily too well on unseen data that is testing dataset.
   - Prevention/Correction Techniques -
     1) Use of suitable model
     2) Scale the data
     3) reduce the noise from the data
     4) cross-validation

7) bias -> Bias is a terminology in machine learning. It originates from a machine learning model predicting poorly in the training phase. Basically the error in the training phase called as bias.

   variance -> Variance is when the model gives error in the testing phase.
   To reduce it we take data that is properly encoded, scaled and the size of the data is moderate.
   bias-variance tradeoff is a scenario where if the model performs poorly in the training phase.
