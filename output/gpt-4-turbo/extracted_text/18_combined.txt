6. Train-test-split:
When we get a new dataset, we have divide the dataset initially into train-test-split; i.e. 70-30% of data are kept initially for training and after training the data model, we use 30-20% of dataset for testing. On this basis, we train the model as well as test the model. Simultaneously, this division of dataset into 70-30% is splitting of data for the purpose of training and testing of data.

7. Overfitting of data and Underfitting:
In overfitting of data, we basically try to fit data more precisely and accurately, we try to cover each and every point possible, which is very strict in nature. And, underfitting of data suggests that we are less concerned of considering any data, we traverse in dataset and whatever number of data we get is the possible data, but it does not give more accurate models, because sample size of data may decrease.

8. General algorithm that are available to minimize Cost function:
- Naïve Bias algorithm

Cost function depends on the regression model, we select, Cost function may reduce for some problem and also may increase for some problem. Basically, Cost function is low for linear regression model and at the same time it is increased for logistic regression model. 
In linear regression, basically we simplify the problem with given datasets, which takes less time than logistic regression problem. So, it will lower the cost function and simultaneously it will increase the cost function for logistic regression problem.

9. Confusion matrix is the essential aspect of learning model, we will get confusion matrix for every model we train, it basically tells about the model in more details, without confusion matrix, we can't be able to tell about the precision, recall, false negative rate, false positive rate of model.

   - TN = 82
   - FP = 3
   - FN = 5
   - TP = 10

   - False negative rate (FNR) = FN / (TN + FN) = 5 / (82 + 5) = 0.05
   - False positive rate (FPR) = FP / (TP + FP) = 3 / (10 + 3) = 0.29
   - Precision = TP / (TP + FP + TN) = 10 / (10 + 3 + 82) = 0.1
   - Recall = TP / (TN + TP) = 10 / (82 + 10) = 0.108

10. Bias and Variance of a Machine Learning model.
   - Bias are dashed (how much deviated from the actual central tendency).
   - Variance is, the how dataset is far from the central nature of a given model.

   To reduce Bias and Variance, we should avoid:
   - Overfitting and underfitting
   - Increase sample size chance model
   - More frequent train-test split.

   Bias-variance trade-off is basically first used to know how much deviation is there in the model, then we adjust the model by knowing how far we are from the Central tendency. 
   This process is called Bias-Variance trade-off.
