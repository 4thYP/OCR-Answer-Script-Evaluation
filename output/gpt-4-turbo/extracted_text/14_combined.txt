8. Linear Regression is supervised algorithm where output as a dependent variable is found from one or more independent variable.

y = ax + b + μ  
a - intercept, b - slope  
y => dependent variable  
x => independent variable

The cost function *L( , )* (loss) function for linear regression is: L = 1/M Σ (y_i - ŷ_i)^2  
y_i => Actual output  
ŷ_i => Predicted output

**Logistic regression** is a supervised algorithm where it is mainly used for classification i.e., classifying the data points into their respective classes.

![Classification Diagram](data:image/jpeg;base64,/9j/2wCEAAoHBwgHBgoJCAkLCwoLDhgQDg0NDhEdFhIYIiohJSklIi IzJjsxMzI6IjIjJk4yODIyOjQyMC0uMyswMTcDELw5OjRBKTsrKzctRj/included various logistic regression formulas)

**The cost function/loss function of logistic regression is:**
  
L = yi log(yi) + (1 - yi)log(1 - y^i)
- > y_i -> Actual output
- > y^i -> Predicted output

**The general algorithm by which lost functions are minimized are Lasso Regression & Ridge Regression**

**For Lasso:**
L(Lasso) = Σ |yi - y^i| + λ|coefficients|
> Here Σ is absolute value of m.

**For Ridge:**
L(Ridge) = Σ (yi - y^i)^2 + λ(m^2)
> λ(called lambda) is a hyperparameter
> m is a squared value of m.
