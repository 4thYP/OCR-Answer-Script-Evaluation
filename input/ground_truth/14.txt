8). Linear Regression is supervised algorithm where output a dependent variable is found from one or more independent variable 
y=a+bx+4
  a → intercept, b → slope
  y → dependent variable
  x → independent variable
The cost function / Loss function for linear regression is :
L=∑_(i=1)^n(y_i-Ŷ_i)
y_i→Actualoutput
Ŷ_i→Predictedoutput

Logistic regression is a supervised algorithm where it is mainly used for the classification, i.e. classifying the data into their respective classes.


The cost function / loss function of Logistic regression is:
L=y_i log⁡(Ŷ_i)+(1-y_i)log⁡(Ŷ_i)
y_i→Actual output
Ŷ_i→P"redicted output"
